## How to run

From the repository root, in PowerShell. Set the encoding first, because the scripts print `§` and `→`. Where `python` is only the Microsoft Store alias, use `py -3` or the full interpreter path in its place; the rest of each command stays the same.

```powershell
$env:PYTHONIOENCODING = 'utf-8'
$env:PYTHONHASHSEED = '0'
$C = '_fixtures/checkers'; $R = '_fixtures/chain/run-2026-10-07-review'
python -B $C/check_links.py $R
python -B $C/_linkcheck.py $R
python -B $C/check_lld_trace.py $R/lld-refunds-platform $R/sdd-refunds-platform REFUNDS=$R/brd-refunds-portal LOYALTY=$R/brd-loyalty-points
python -B $C/check_trace.py $R
python -B $C/check_sdd.py $R/sdd-refunds-platform
python -B $C/check_e2e.py $R/sdd-refunds-platform
python -B $C/check_uc_links.py $R/sdd-refunds-platform
python -B $C/check_uc_keys.py $R/sdd-refunds-platform
foreach ($D in 'brd-refunds-portal', 'brd-loyalty-points', 'sdd-refunds-platform', 'lld-refunds-platform') {
    python -B $C/_linkcheck.py $R/$D
    python -B $C/check_versions.py $R/$D
    python -B $C/check_mermaid.py $R/$D
}
foreach ($D in 'brd-refunds-portal', 'brd-loyalty-points') { python -B $C/check_todo.py $R/$D }
python -B $C/check_todo.py _fixtures/scenarios/pre-brd-to-brd/rerun-2026-10-07-s7/brd-clinic-reminders
python -B $C/list_flags.py $R/lld-refunds-platform
python -B $C/check_refs.py lld-unifier sdd-unifier
python -B $C/diff_runs.py _fixtures/chain/run-new $R --levels 2
```

With `$R` set to the baseline, every command reports 0 problems; `check_sdd.py` and `check_e2e.py` each print 1 accepted note. `check_e2e.py` also prints an `E4 note:` line, outside its notes count: the baseline's Reconciled entry records `sha256 c8dbd190559473ea` by an earlier method (file names and NUL separators), not as a `sha256:` E4 hash, so its E4 is judged by date. The `check_todo.py` line for the S3 scenario `rerun-2026-10-07-s7` does not use `$R` and shows its known problem (TD-88 Blocks names only `decision-log.md`; see the `check_todo.py` row under [Checkers](#checkers)); the scenario is frozen evidence, so it stays.

To test a new run, write it to the session scratchpad (never inside a skill folder) with the same folder names, point `$R` at it, and compare it with `diff_runs.py`. When a run passes and is selected as the baseline, keep its dated path and update this default; older runs remain comparison evidence.
