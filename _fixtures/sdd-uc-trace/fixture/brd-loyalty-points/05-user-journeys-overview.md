# User Journeys & Use Cases

## User Journeys

### Customer Journey

The customer checks their points balance and history, and turns points into a voucher when they have enough.

### Loyalty Manager Journey

The loyalty manager finds a customer, checks their points history, and corrects the balance with a reason.

## Use Case Summary

| UC ID | Use Case | Primary Actor | Description |
|-------|----------|---------------|-------------|
| **Customer** | | | |
| UC-01 | View Points Balance | Customer | The customer sees their balance and how it changed. |
| UC-02 | Redeem Points for a Voucher | Customer | The customer turns points into a voucher. |
| **Loyalty Manager** | | | |
| UC-03 | Adjust a Customer's Points | Loyalty Manager | The loyalty manager adds or removes points with a reason. |
