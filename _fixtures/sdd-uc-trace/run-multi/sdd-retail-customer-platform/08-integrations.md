# 12. Integrations

One row per external system. A partner named in both source BRDs has one row that cites each BRD's integration row. Retries with exponential backoff and jitter, circuit breakers, and bulkheads (Resilience4j) are the platform defaults on every adapter; provider-owned fields stay `TBD - external` until the provider documentation is supplied, and every synchronous API gets its contract in §15 (part 2).
